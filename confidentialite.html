Politique de confidentialité

Dernière mise à jour : 23 mai 2026

1. Objet

La présente politique de confidentialité explique comment WebPronto collecte, utilise et protège les données personnelles transmises via le site webpronto.fr, notamment par l’intermédiaire du formulaire de contact.

WebPronto accorde de l’importance à la confidentialité des données personnelles et s’engage à ne collecter que les informations nécessaires à la gestion des demandes reçues.

3. Données collectées

Lorsque vous utilisez le formulaire de contact du site, WebPronto peut collecter les données suivantes :

  • nom ;
  • entreprise ;
  • adresse email ;
  • téléphone, lorsque vous le renseignez ;
  • secteur d’activité ;
  • type de besoin ;
  • contenu du message ;
  • informations techniques nécessaires au bon fonctionnement du formulaire.

Les champs obligatoires sont indiqués dans le formulaire. Le numéro de téléphone est facultatif.

4. Finalités du traitement

Les données collectées sont utilisées pour :

  • répondre à vos demandes ;
  • comprendre votre besoin ;
  • établir un premier diagnostic ;
  • préparer un devis ;
  • assurer le suivi commercial ;
  • organiser une prestation lorsqu’une collaboration est engagée ;
  • conserver un historique des échanges professionnels.

WebPronto n’utilise pas ces données pour envoyer une newsletter commerciale automatisée, sauf consentement spécifique ultérieur.

5. Base légale du traitement

Les traitements sont fondés sur :

  • l’intérêt légitime de WebPronto à répondre aux demandes professionnelles reçues ;
  • l’exécution de mesures précontractuelles lorsque vous demandez un devis ou un diagnostic ;
  • l’exécution d’un contrat lorsqu’une prestation est engagée ;
  • le respect d’obligations légales lorsqu’une conservation est imposée par la réglementation.

6. Destinataires des données

Les données sont destinées à WebPronto.

À ce jour, les demandes reçues via le formulaire sont accessibles uniquement par WebPronto.

Certaines données peuvent transiter par des prestataires techniques utilisés pour faire fonctionner le site ou le formulaire, notamment :

  • GitHub Pages pour l’hébergement du site ;
  • Formspree pour le traitement du formulaire de contact ;
  • le prestataire email utilisé pour recevoir les notifications.

7. Transferts hors Union européenne

Certains prestataires techniques utilisés par WebPronto, notamment GitHub ou Formspree, peuvent être établis hors de l’Union européenne ou traiter certaines données hors de l’Union européenne.

Lorsque cela est applicable, WebPronto s’efforce d’utiliser des prestataires prévoyant des garanties adaptées en matière de protection des données.

8. Durée de conservation

Les données issues des demandes de contact sont conservées pendant une durée maximale de 3 ans à compter du dernier échange avec le prospect, sauf demande de suppression avant ce délai.

Les données nécessaires à la facturation, à la comptabilité ou à la preuve d’une relation contractuelle peuvent être conservées pendant la durée légale applicable.

9. Droits des personnes

Conformément à la réglementation applicable, vous pouvez demander :

  • l’accès à vos données ;
  • la rectification de données inexactes ;
  • l’effacement de vos données ;
  • la limitation du traitement ;
  • l’opposition au traitement, lorsque cela est applicable ;
  • la portabilité de vos données, lorsque cela est applicable.

Pour exercer vos droits, vous pouvez écrire à contact@webpronto.fr.

WebPronto pourra vous demander des informations complémentaires afin de vérifier votre identité si nécessaire.

10. Sécurité

WebPronto met en œuvre des mesures raisonnables pour protéger les données personnelles contre l’accès non autorisé, la perte, l’altération ou la divulgation.

Les accès aux outils techniques sont limités aux besoins strictement nécessaires. WebPronto évite autant que possible la transmission de mots de passe en clair et privilégie les invitations utilisateurs, comptes dédiés ou méthodes d’accès sécurisées.

11. Données sensibles

WebPronto ne souhaite pas collecter de données sensibles via le formulaire de contact.

Il est demandé aux utilisateurs de ne pas transmettre, via le formulaire, d’informations sensibles telles que données médicales, données financières détaillées, données relatives à des mineurs, données RH sensibles, identifiants confidentiels ou mots de passe.

12. Réclamation

Si vous estimez que vos droits ne sont pas respectés, vous pouvez contacter WebPronto à l’adresse contact@webpronto.fr.

Vous disposez également du droit d’introduire une réclamation auprès de la CNIL.
